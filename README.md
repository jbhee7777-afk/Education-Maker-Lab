# 크리스마스 활동 키트

초등 저·중·고학년용 크리스마스 수업 자료 모음입니다. `index.html`을 브라우저로 열면 학년군과 종류별로 자료를 고를 수 있습니다.

## 들어 있는 것

| 구분 | 내용 |
| --- | --- |
| 인쇄 활동지 | 75종, 137쪽 (`sheet.html#<활동 id>`) |
| 바로 인쇄용 PDF | `print/` 폴더 (활동지 75종 + 정답지 23종) |
| 가벼운 PDF 묶음 | `print-small/` 폴더 (학년별 · 종류별 21개, 파일당 0.4~5MB) |
| 전자칠판 게임·도구 | `games/` 폴더 11종 |
| 일러스트 | 캐릭터 40종(컬러·색칠용 선 그림), 장면·도안 그림 30장, 나라별 그림 12종, 컵타·종이접기 사진 그림 |

활동지는 첫 화면 안에서 바로 열립니다(주소 `index.html#<활동 id>`). 활동지 화면 위쪽의 `저학년 / 중학년 / 고학년` 버튼을 누르면 같은 활동의 다른 학년용으로 바로 바뀝니다. 옆 목록에서 그 학년의 다른 활동지로 바로 넘어갈 수도 있습니다.

### 활동지 종류

- **컬러링**: 캐릭터 컬러링, 학년별 장면 컬러링(저 4장·중 4장·고 4장, 한옥 마당 눈사람 포함), 만다라 2종, 숫자·곱셈·코딩 픽셀 컬러링, 대칭 그리기, 못난이 스웨터, 젠탱글, 카드 표지, 쿠키 꾸미기
- **만들기**: 끼워 만드는 입체 장식 4종(트리·눈사람·별·공), 소원 오너먼트, 트리 오너먼트 카운트다운, 루돌프 머리띠, 미션 주사위 말판 놀이, 착시 장난감(소마트로프), 두 얼굴 그림, 팝업 카드, 친절 종이 고리, 쿠폰북, 책갈피, 손가락 인형, 눈사람 옷 입히기, 선물 이름표, 오려 거는 종이 오너먼트
- **종이접기**: 산타 모자, 루돌프 얼굴, 루돌프 모서리 책갈피, 3단 트리, 여섯 갈래 눈꽃 (완성 모습 그림 포함)
- **놀이·퍼즐**: 미로, 숨은 그림 세기(고학년은 그래프), 낱말 찾기, 그림·좌표 암호, 한 장면 속 다른 그림 찾기(학년별 3장면), 빙고판, 그림자 짝, 규칙 찾기, 덧셈·뺄셈, 선 긋기, 점 잇기, 주사위 그리기, 선물 가게 수학, 파티 자리 배치 추리, 썰매 말판, 교실 놀이 카드 12선, 왼쪽·오른쪽 선물 돌리기 이야기
- **글쓰기·마음 나눔**: 산타 편지, 엘프 지원서, 세계의 크리스마스 여행(나라별 그림), 스노우볼 상상 글, 주사위 이야기, 세 가지 선물, 친절 어드벤트 달력, 인증서
- **노래**: 학년별 징글벨 컵타 악보(동작 사진 카드 포함), 캐럴 노랫말 바꿔 부르기

캐럴 노래방에는 가사 줄마다 한글 발음과 우리말 뜻이 함께 나옵니다.

미로·낱말 찾기·암호처럼 「매번 새 문제」 표시가 있는 활동지는 `새 문제로 바꾸기`를 누를 때마다 새로 만들어집니다.

### 전자칠판 게임 (`games/`)

산타 작업실 방탈출, 산타 퀴즈 쇼, 두근두근 선물 상자, 짝꿍 카드 기억력 게임, 산타 모자 속 선물 찾기, 나는 누구일까요(그림자·확대·초성), 몸으로 말해요, 메리 빙고 뽑기, 리스 돌림판, 눈사람 타이머·썰매 경주, 캐럴 노래방.

게임마다 오른쪽 위에서 학년군을 바꾸면 난이도와 문제가 바뀝니다. 아래쪽 모둠 점수판은 1~6모둠을 지원합니다.

## 사용 방법

1. 저장소를 내려받아 `index.html`을 크롬이나 엣지로 엽니다. (인터넷 연결 없이도 동작합니다)
2. 활동지는 `인쇄하기`(Ctrl+P)로 인쇄하거나 `print/` 폴더의 PDF를 씁니다. A4, 여백 없음, 배경 그래픽 켜기를 추천합니다.
3. 게임은 전자칠판에서 열고 `전체화면`을 누릅니다. 효과음이 있으니 스피커를 켜 두세요.

## 출처와 라이선스

- 일러스트: Figma AI 이미지 생성으로 이 키트를 위해 만든 그림입니다. 원본 그림은 Figma 파일 「크리스마스 활동 키트 일러스트」에 있습니다.
- 글꼴: 주아(Jua), 고운돋움(Gowun Dodum), 개구(Gaegu). 모두 SIL Open Font License이며 `assets/fonts/`에 라이선스 전문이 있습니다.
- 캐럴: Jingle Bells(1857), We Wish You a Merry Christmas(영국 전래), Deck the Halls(웨일스 전래), Silent Night(1818)은 저작권이 만료된 공개 저작물입니다. 반주는 브라우저에서 직접 합성합니다.

## 폴더 구조

```
index.html          키트 첫 화면
sheet.html          활동지 보기·인쇄 화면
games/              전자칠판 게임
print/              인쇄용 PDF
assets/             공통 스타일, 스크립트, 글꼴, 그림
  img/c  img/l      캐릭터 컬러 / 색칠용 선 그림
  img/page          장면 그림, 컬러링 전면 그림
  sheets-a.js       활동지 (컬러링·퍼즐·놀이)
  sheets-b.js       활동지 (만들기·종이접기·글쓰기·놀이 카드·노래)
  quiz-bank.js      퀴즈 문제 은행
```
